# AED Placement Optimizer: Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the core of the AED placement optimizer (shared data format, synthetic campus, travel times, survival, coverage, ILP, greedy) and produce a lives-saved-vs-K curve, so teammates A–D can build their modules on frozen interfaces.

**Architecture:** Plain-function modules joined by one `Instance` dataclass (numpy arrays). The `Instance` and `Params` are turned into a sparse `Coverage` (rows = cell × period × time band, columns = sites), and every solver consumes `Coverage`. All solvers report lives saved through the same `evaluate` function.

**Tech Stack:** Python 3.11, numpy, scipy ≥ 1.9 (`scipy.optimize.milp`, HiGHS), matplotlib, pytest.

**Spec:** `docs/superpowers/specs/2026-10-17-aed-placement-design.md`

## Global Constraints

- Python 3.11; dependencies: `numpy`, `scipy>=1.9`, `matplotlib`, `pytest` (core). `streamlit`, `folium`, `streamlit-folium` are listed in `requirements.txt` for teammate C but not imported by core.
- The ILP stays linear: time bands and lockout availability are data, not variables.
- Coordinates in local metres; times in seconds at all function boundaries; `survival_k_per_min` is per minute.
- Every parameter in `params.py` has a base value, a (low, high) range and a citation string or the literal prefix `ASSUMPTION:`.
- Objective units: expected lives saved per year compared with the ambulance-only baseline.
- Pairs with τ_ij > `max_tau_s` (600 s) are pruned.
- Existing AEDs are forced on (x_j = 1) and cost 0.
- Run tests from the repo root with `python -m pytest`.
- Commit on branch `aed-core`; message trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Budget = 0 (K = 0):** solvers return only the existing AEDs with lives = `evaluate` of that set, without crashing. → Task 5 `test_zero_budget`, Task 6 `test_greedy_zero_budget`.
2. **A period where every site is locked:** that period contributes 0 and nothing errors. → Task 4 `test_all_closed_period`.
3. **A cell with no site within `max_tau_s`:** it produces no coverage rows; nothing errors. → Task 4 `test_unreachable_cell`.
4. **`ems_response_s` at or below the first band edge:** all benefits are 0, so the coverage has 0 rows and solvers return lives = 0. → Task 4 `test_ems_faster_than_all_bands`, Task 5 `test_empty_coverage`.
5. **Budget larger than the total cost of all sites:** solvers select every site and do not loop or fail. → Task 6 `test_budget_exceeds_all`.

### Task 4: Coverage, evaluate, pipeline

**Files:**
- Create: `aed/coverage.py`, `aed/solvers/__init__.py`, `aed/solvers/common.py`, `aed/pipeline.py`
- Test: `tests/test_coverage.py`

**Interfaces:**
- Consumes: Tasks 1–3.
- Produces:
  - `@dataclass class Coverage`: `A: scipy.sparse.csr_matrix` (R × J, 0/1), `weights: np.ndarray` (R,), `row_cell`, `row_period`, `row_band: np.ndarray` (R,) int, `site_cost: np.ndarray` (J,), `site_existing: np.ndarray` (J,) bool, `n_periods: int`.
  - `build_coverage(inst: Instance, tau: np.ndarray, params: Params) -> Coverage`. Uses the **incremental form** from spec §5: with `(edges, b) = band_benefits(params)` and `Δb_k = b_k − b_{k+1}` (b past the last band = 0), there is one row per (i, p, k) with `λ_ip·Δb_k > 0` that has at least one site j with `tau[i,j] ≤ min(edges[k], max_tau_s)` and `site_open[j,p]`. Its row in A marks those sites and its weight is `λ_ip·Δb_k`. Covered rows are summed and no Σ_k ≤ 1 constraint is needed, because the sets are nested in k and the sum telescopes to `λ_ip·b_{k*}` for the fastest band k*.
  - `@dataclass class Solution`: `x: np.ndarray` (J,) bool, `lives: float`, `method: str`, `runtime_s: float`, `mip_gap: float | None = None`.
  - `evaluate(cov: Coverage, x: np.ndarray) -> float` = `weights[(A @ x.astype(float)) >= 1].sum()`.
  - `evaluate_by_period(cov: Coverage, x: np.ndarray) -> np.ndarray` of shape (P,).
  - `pipeline.build(seed: int = 0, params: Params | None = None, **gen_kwargs) -> tuple[Instance, Coverage]`.

```python
def brute_lives(inst, tau, p, x):
    """Direct spec formula: Σ_ip λ_ip · b(fastest open selected site)."""
    edges, b = band_benefits(p); total = 0.0
    for i in range(inst.n_cells):
        for q in range(inst.n_periods):
            ok = x & inst.site_open[:, q] & (tau[i] <= p.max_tau_s)
            if ok.any():
                t = tau[i, ok].min(); k = np.searchsorted(edges, t)  # first edge ≥ t
                if k < len(b): total += inst.cell_rate[i, q] * b[k]
    return total

def test_evaluate_matches_direct_formula(tiny_instance):
    p = Params(); tau = travel_time_matrix(tiny_instance, p)
    cov = build_coverage(tiny_instance, tau, p)
    rng = np.random.default_rng(0)
    for _ in range(10):
        x = rng.random(8) < 0.4
        assert evaluate(cov, x) == pytest.approx(brute_lives(tiny_instance, tau, p, x))

def test_all_closed_period(tiny_instance):
```

### Task 5: ILP solver

**Files:**
- Create: `aed/solvers/ilp.py`

**Interfaces:**
- Consumes: `Coverage`, `Solution`, `evaluate` (Task 4).
- Produces: `solve_ilp(cov: Coverage, budget: float, time_limit_s: float = 60.0, mip_rel_gap: float = 1e-4) -> Solution` with `method="ilp"`. `lives` is recomputed with `evaluate` on the rounded x; `mip_gap` comes from the HiGHS result.

Formulation for `scipy.optimize.milp`: variables `[x (J) binary, z (R) continuous in [0,1]]`; minimize `−weights·z`; constraints `z_r − Σ_j A_rj x_j ≤ 0` (sparse block `[−A | I]`, upper bound 0), `site_cost·(x ∧ ¬existing) ≤ budget`; bounds `x_j ∈ [1,1]` for existing sites and `[0,1]` otherwise. When R = 0, skip the solve and return the existing set only.

### Task 6: Greedy baseline

**Files:**
- Create: `aed/solvers/greedy.py`
- Test: `tests/test_greedy.py`

**Interfaces:**
- Consumes: `Coverage`, `Solution`, `evaluate`.
- Produces: `solve_greedy(cov: Coverage, budget: float) -> Solution` with `method="greedy"`. Start from the existing sites and repeatedly add the affordable site with the largest `marginal_gain / cost` (lazy evaluation with a max-heap of stale upper bounds; marginal gain = sum of weights of rows that are not yet covered and that the site covers). Stop when no affordable site has gain > 0.
