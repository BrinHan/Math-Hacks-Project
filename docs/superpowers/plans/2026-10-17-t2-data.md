Model (values fixed by the plan test). Every constant gets a module-level comment saying `ASSUMPTION:` and why.
- Periods/hours/anchor unchanged: `["day","evening","night"]`, `[10, 6, 8]`, `(43.4723, -80.5449)`.
- `PEOPLE` per kind, (day, evening, night): academic (800, 100, 0), library (400, 300, 50), residential (150, 500, 600), athletic (200, 300, 0), dining (300, 250, 0).
- `KIND_P = {"academic": 0.35, "residential": 0.30, "dining": 0.13, "library": 0.12, "athletic": 0.10}`.
- `BACKGROUND_PER_HA = (12.8, 7.7, 2.6)` people per hectare (day, evening, night); per-cell background = density × cell area in ha (cell area = (extent_m/grid_n)² / 10,000). Equals (5, 3, 1) per cell at the defaults.
- `SIGMA_M = 60.0`, `SITE_JITTER_M = 30.0`, `OUTDOOR_SHARE = 0.10`.

**RNG draw order (fixed, all from one `rng = np.random.default_rng(seed)`):**
1. Kinds: first `min(n_buildings, 5)` are academic, residential, library, dining, athletic in that order; then `rng.choice(list(KIND_P), size=n_buildings-5, p=list(KIND_P.values()))` if `n_buildings > 5`.
2. Sizes: `rng.uniform(0.5, 2.0, size=n_buildings)`.
3. Centres, one loop over buildings in index order: academic/library/dining → `rng.normal(c, 0.15*extent_m, size=2)`; residential → `a = rng.uniform(0, 2π)`, `r = rng.uniform(0.30, 0.42)*extent_m`, `c + r·(cos a, sin a)`; athletic → `rng.uniform(0.05*extent_m, 0.95*extent_m, size=2)`. Then clip all centres to `[0.03, 0.97]·extent_m`.
4. Indoor allocation: `n_outdoor = max(1, round(OUTDOOR_SHARE*n_sites))`, `n_indoor = n_sites − n_outdoor`. If `n_indoor >= n_buildings`, give one site to every building and allocate the rest with `rng.multinomial(n_indoor − n_buildings, size/size.sum())`; otherwise `rng.multinomial(n_indoor, size/size.sum())`.
5. Indoor sites, loop over buildings in index order then site within building: `ang = rng.uniform(0, 2π)`, `rad = rng.uniform(0, SITE_JITTER_M)`; position clipped to `[0, extent_m]`; kind = building kind; open in period p iff `PEOPLE[kind][p] > 0`; floor delay `30 + 90·(size − 0.5)/1.5` s; cost 1.0.
6. Outdoor sites: `rng.uniform(0, extent_m, size=(n_outdoor, 2))`, kind `"outdoor"`, always open, floor delay 0, cost `outdoor_cost`.
7. Site order in the `Instance`: indoor sites first (building order), then outdoor.
8. Existing AEDs: `rng.choice(n_indoor, size=min(n_existing, n_indoor), replace=False)`.

Demand: cell people per period = Σ_b people_b · kernel(cell, b) + background, where the Gaussian kernel (σ = 60 m) is normalised over cells so each building's people sum exactly to its total. `cell_rate = pop × incidence/1e5 × public_fraction × period_hours/24` (unchanged formula).

`docs/assumptions.md` "Synthetic campus" section must state: building occupancy profiles; academic buildings open until midnight with evening occupancy; residential halls counted at night (residents' common areas and lobbies treated as public, AED in a card-access lobby assumed reachable), which likely overstates night public risk; general-population incidence applied to a young campus population (overstates risk); σ, jitter, outdoor share and cabinet cost are illustrative.

    p = Params()

def test_demand_is_concentrated():

    # One academic building: building people (total minus background) keep the 800:100 day:evening ratio.

### Task 2: Population-only baseline

**Files:**
- Create: `aed/solvers/population.py`, `tests/test_population.py`. Do not edit other solver files.

**Interfaces:**
- Consumes: `Instance`, `Coverage`, `Solution`, `evaluate`, `Params`.
- Produces: `solve_population(inst: Instance, cov: Coverage, budget: float, radius_s: float = 180.0, params: Params | None = None) -> Solution` with `method="population"`. Definition (state it in the docstring): score of site j = Σ_i Σ_p `cell_rate[i, p]` over cells whose **one-way walking time** `detour_factor · ‖cell_i − site_j‖ / walk_speed_mps ≤ radius_s` (no dispatch delay, no round trip, no floor delay; 180 s ≈ 194 m at the defaults). Opening hours and survival are ignored. Start from the existing AEDs; walk non-existing sites in descending score (stable: ties by lower index), adding each whose cost fits the remaining budget, including zero-score sites if budget remains. `lives = evaluate(cov, x)`.

- [ ] **Step 1: Write failing tests** (imports: `numpy as np`, `build` from `aed.pipeline`, `evaluate` from `aed.solvers.common`, `solve_ilp` from `aed.solvers.ilp`, `solve_population` from `aed.solvers.population`, `Params` from `aed.params`):

```python
SMALL = dict(grid_n=12, n_buildings=8, n_sites=40, n_existing=2)

def _score(inst, radius_s=180.0):
    p = Params()
    d = np.linalg.norm(inst.cell_xy[:, None] - inst.site_xy[None], axis=2)
    walk = p.detour_factor * d / p.walk_speed_mps
    return np.where(walk <= radius_s, inst.cell_rate.sum(1)[:, None], 0.0).sum(0)

def test_population_within_budget_and_below_ilp():
    inst, cov = build(seed=0, **SMALL)
    for K in (2, 5):
        pop, opt = solve_population(inst, cov, K), solve_ilp(cov, K)
        assert cov.site_cost[pop.x & ~cov.site_existing].sum() <= K + 1e-9
        assert evaluate(cov, cov.site_existing) - 1e-9 <= pop.lives <= opt.lives * (1 + 1e-4) + 1e-9
        assert pop.method == "population" and pop.x[cov.site_existing].all()

def test_population_zero_budget():
    inst, cov = build(seed=0, **SMALL)
    assert np.array_equal(solve_population(inst, cov, 0).x, cov.site_existing)

def test_population_picks_busiest_site_first():
    inst, cov = build(seed=0, grid_n=12, n_buildings=8, n_sites=40, n_existing=0, outdoor_cost=1.0)
    assert solve_population(inst, cov, 1).x[np.argmax(_score(inst))]

def test_population_scores_are_informative():
    inst, _ = build(seed=0, **SMALL)
    assert (_score(inst) > 0).mean() > 0.8      # radius on one-way walk, not on full response time
```
