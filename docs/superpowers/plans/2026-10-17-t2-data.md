Model (values fixed by the plan test):
- Periods/hours/anchor unchanged: `["day","evening","night"]`, `[10, 6, 8]`, `(43.4723, -80.5449)`.
- Building kinds and people per period (day, evening, night): academic (800, 100, 0), library (400, 300, 50), residential (150, 500, 600), athletic (200, 300, 0), dining (300, 250, 0). Kind assignment: the first `min(n_buildings, 5)` buildings are academic, residential, library, dining, athletic in that order; the rest are drawn with probabilities academic 0.35, residential 0.30, dining 0.13, athletic 0.10, library 0.12.
- Size factor `rng.uniform(0.5, 2.0)` per building multiplies its people.
- Layout: academic/library/dining centres ~ Normal(centre, 0.15·extent) per axis; residential on a ring at radius `uniform(0.30, 0.42)·extent` around the centre; athletic uniform in `[0.05, 0.95]·extent`. Clip all centres to `[0.03, 0.97]·extent`.
- Cell population per period = Σ_b people_b · kernel(cell, b) + background (5, 3, 1). Kernel: Gaussian with σ = 60 m, normalised over cells so each building's people sum exactly to its total.
- `cell_rate = pop × incidence/1e5 × public_fraction × period_hours/24` (unchanged formula).
- Sites: `n_outdoor = max(1, round(0.1·n_sites))` outdoor cabinets (uniform in the square, always open, floor delay 0, cost `outdoor_cost`, kind `"outdoor"`). The other sites are allocated to buildings with `rng.multinomial(n_indoor, size/size.sum())`, placed at uniform angle and uniform radius 0–30 m from the building centre, clipped to the square; kind = building kind; open in period p iff the kind's nominal people in p > 0; floor delay `30 + 90·(size − 0.5)/1.5` s; cost 1.0.
- `n_existing` existing AEDs: random indoor sites (without replacement), capped at the indoor count.

### Task 2: Population-only baseline

**Files:**
- Create: `aed/solvers/population.py`, `tests/test_population.py`. Do not edit other solver files.

**Interfaces:**
- Consumes: `Instance`, `Coverage`, `Solution`, `evaluate`, `travel_time_matrix`, `Params`.
- Produces: `solve_population(inst: Instance, cov: Coverage, budget: float, radius_s: float = 180.0, params: Params | None = None) -> Solution` with `method="population"`. Score of site j = Σ_i Σ_p `cell_rate[i, p]` over cells with `tau[i, j] ≤ radius_s` (tau from `travel_time_matrix(inst, params or Params())`), **ignoring opening hours and survival**. Start from the existing AEDs; walk non-existing sites in descending score (ties by index), adding each one whose cost still fits the remaining budget. `lives = evaluate(cov, x)`.

SMALL = dict(grid_n=12, n_sites=40, n_existing=2)

def test_population_within_budget_and_below_ilp():
    inst, cov = build(seed=0, **SMALL)
    for K in (2, 5):
        pop, opt = solve_population(inst, cov, K), solve_ilp(cov, K)
        assert cov.site_cost[pop.x & ~cov.site_existing].sum() <= K + 1e-9
        assert evaluate(cov, cov.site_existing) - 1e-9 <= pop.lives <= opt.lives + 1e-9
        assert pop.method == "population" and pop.x[cov.site_existing].all()

def test_population_zero_budget():
    inst, cov = build(seed=0, **SMALL)
    assert np.array_equal(solve_population(inst, cov, 0).x, cov.site_existing)

def test_population_picks_busiest_site_first():
    inst, cov = build(seed=0, n_existing=0, **{k: v for k, v in SMALL.items() if k != "n_existing"})
    tau = travel_time_matrix(inst, Params())
    score = np.where(tau <= 180, inst.cell_rate.sum(1)[:, None], 0).sum(0)
    assert solve_population(inst, cov, 1).x[np.argmax(score)]

def test_population_deterministic():
    inst, cov = build(seed=1, **SMALL)
    assert np.array_equal(solve_population(inst, cov, 4).x, solve_population(inst, cov, 4).x)
